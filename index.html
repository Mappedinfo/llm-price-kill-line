⑥ 方法论、口径与注意事项Methodology

计算口径

  1. 混合价 = 0.7×缓存 + 0.2×输入 + 0.1×输出,权重与 Artificial Analysis 官方一致,便于横向可比;切换输入/输出口径请用上方按钮。
  2. 能力分 = AA Intelligence Index v4.1.1(智能体34% + 编码24% + 科学推理24% + 通用18%,9 项基准加权)。同一模型的不同推理力度档位取最高档。
  3. 斩杀(被支配):存在另一个在售渠道报价 ≤ 本报价,且能力分 ≥ 本模型 → 被斩杀。斩杀线 = 帕累托前沿,阶梯连接。
  4. 人民币价格按 2026-08-27 中间价 6.784 折算,不构成支付汇率。
  5. 免费限量模型不参与斩杀计算(请求次数限制使每token价不可比)。
